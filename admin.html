Como ver mais detalhes

Se estiver usando o Supabase, entre no painel do projeto → SQL Editor e rode as consultas de exemplo comentadas no arquivo supabase/schema.sql (ou veja o README.md) para relatórios mais detalhados, como participantes por dia.

Se estiver usando o banco local (sqlite-local), use o botão "Exportar banco (.sqlite)" acima e abra o arquivo baixado em qualquer programa leitor de SQLite (ex.: extensão "SQLite Viewer" ou o site sqliteviewer.app) — lembre que, nesse modo, cada navegador guarda seus próprios dados, sem centralização.
