Sobre seus dados (privacidade)

Para este projeto acadêmico de extensão, coletamos o nome/apelido que você digitar, suas respostas e o seu resultado no quiz. Essas informações são usadas apenas para gerar estatísticas de participação do projeto (quantas pessoas participaram e o desempenho geral do grupo) para o relatório acadêmico. Seus dados não são vendidos nem usados para nenhum outro fim.
